# Workshop JavaScript Sesi 1

Project ini berisi latihan dasar JavaScript yang mencakup penggunaan `alert`, `prompt`, `confirm`, `while`, `for`, `array`, dan `switch case`.

## Deskripsi

Project ini terdiri dari 2 program utama yang dibuat untuk memahami konsep dasar pemrograman JavaScript:

### 1. Program Luas Persegi Panjang
Program ini meminta pengguna memasukkan panjang dan lebar, kemudian menghitung luasnya. Setelah itu, program akan membandingkan jawaban user dengan hasil perhitungan, lalu menampilkan apakah jawaban benar atau salah.

Fitur yang digunakan:
- `alert()`
- `prompt()`
- `confirm()`
- `while` loop
- operasi matematika sederhana

### 2. Program Array dan Switch Case
Program ini berisi latihan mengenai operasi array dan pemilihan kondisi:
- penjumlahan seluruh elemen array
- pemisahan bilangan genap dan ganjil
- menampilkan hari dalam seminggu menggunakan `switch case`

Fitur yang digunakan:
- `for` loop
- `while` loop
- `array`
- `push()`
- `switch`
- `Date().getDay()`

---

## Cara Menjalankan

1. Buka folder project ini.
2. Jalankan file `index.html` di browser.
3. Pastikan `index.js` sudah terhubung dengan benar pada file HTML.

Jika ingin melihat hasil di browser, Anda dapat membuka file HTML lalu program JavaScript akan otomatis berjalan.

## Contoh Output

### Program 1
- Input panjang = 10
- Input lebar = 5
- Hasil luas = 50
- User akan diminta memasukkan jawaban
- Program akan menampilkan:
  - `Jawaban anda benar`
  - atau `Jawaban anda salah`

### Program 2
- Array: `[20, 21, 22, 23, 24, 25]`
- Hasil penjumlahan = `135`
- Bilangan genap: `[2, 4, 6, 8, 10]`
- Bilangan ganjil: `[1, 3, 5, 7, 9]`
- Hari aktif ditampilkan sesuai hari saat ini
